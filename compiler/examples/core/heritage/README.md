# Héritage et polymorphisme

Lancer depuis le dossier `compiler` :

```bash
node bin/berkios.mjs core examples/core/heritage/animaux-fr.bks
```

Cet exemple montre l'héritage des champs (`nom`), les constructeurs incluant les champs parents, et la redéfinition de `parler()` sélectionnée selon la classe concrète de l'instance.
